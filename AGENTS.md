# User rules for this project

These rules apply to this folder and all its subfolders, including website code,
design assets, and Blender scenes/models used for this project.

## Ask before changing designs or code

- Before making any design change, explain the specific proposed change and ask
  the user for approval. Wait for their explicit approval before applying it.
- Before editing code, explain what will change and ask the user for approval.
  Wait for their explicit approval before editing.
- A request to inspect, review, test, or suggest improvements is not permission
  to modify designs or code.
- Once a concrete change is approved, perform only that approved scope. Ask again
  before making additional design or code changes outside that scope.
- Read-only inspection and analysis may proceed without further approval.
- Preserve existing user changes; do not overwrite or revert unrelated work.

## Maintaining these rules

- Record additional rules here when the user provides them for this project.
- The user explicitly authorized creating this rules file. That authorization
  does not authorize changes to the website, code, artwork, or Blender files.

## Test until the requested result is verified

- Before delivering the final output, test the actual behavior against the user's
  requested result. Do not treat an edit or a successful build as completion.
- Repeat testing and fix issues within the approved scope until the requested
  behavior is correct. Check relevant desktop/mobile layouts and interactions.
- Ask before making changes outside the approved scope.
- If a blocker prevents verification, state it clearly instead of claiming the
  result is complete. Report what was tested and any remaining limitations.
